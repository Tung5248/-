# 長照速包錢｜老五老基金會和美中心

老五老基金會和美中心自創的「長照四包錢」快速試算工具。

## GitHub Pages

1. 將本資料夾內的 `index.html`、`icon.jpg`、`manifest.webmanifest` 上傳到 GitHub repository。
2. 到 **Settings → Pages**。
3. Source 選擇 **Deploy from a branch**，選擇 `main` 與 `/ (root)`。
4. 儲存後即可透過 GitHub Pages 開啟。

## 檔案

- `index.html`：網站主程式，已可直接開啟。
- `icon.jpg`：**使用者提供的原始 Logo 圖檔，未修改、未重繪、未轉檔。**
- `manifest.webmanifest`：網站／加入主畫面所需的基本設定。
